**Target Component:** `src/features/analytics/components/post-analytics/PostAnalytics.tsx` (Assumed based on UI)

## API Contract

**Endpoint:** `GET /posts/:postId/analytics`
**Query Parameters:**
- `range`: Time range filter (e.g., `7d`, `30d`, `all_time`). Default `30d`.

## 1. Database Schema Additions (Required for Direct Impact)

To track "actions taken directly from this post", we need attribution in our events. We should update the previous database plan (`01_database_schema_updates.md`) or add these requirements here:

- **`profile_views` table update**: Add `source_post_id UUID REFERENCES posts(post_id)` to track if a profile view came from clicking the author's name on a specific post.
- **`followers` table update**: Add `source_post_id UUID REFERENCES posts(post_id)` to track if a follow action was initiated directly from a post (e.g., via a "Follow" button on the post itself or immediately after viewing it).

## 2. Business Logic & Implementation Flow

### A. Post Details & Content Performance
- **Post Details**: Fetch the post by `:postId`. Extract title, snippet, type, and publish date.
- **Content Performance**: 
  - Query `post_analytics_daily` for the given `:postId` over the `range`.
  - Sum the `impressions` (views), `likes`, `comments`, `shares`, and `saves`.
  - Calculate `Engagement Rate` = `((Likes + Comments + Shares + Saves) / Impressions) * 100`. Round to nearest integer and append `%`.
  - Use a backend formatter to abbreviate large numbers (e.g., `12400` -> `"12.4k"`).

### B. Total Reach Chart
- Query `post_analytics_daily` for `:postId` grouped by `date` over the `range`.
- Select `date` and `impressions` (representing daily reach).
- Map to `labels` (array of dates) and `datasets[0].data` (array of daily impressions).

### C. Direct Impact Computation
- **Profile Visits**: 
  - Query `profile_views` where `profile_owner_id = :userId` AND `source_post_id = :postId` within `current_period`.
  - To calculate `vs avg` trend: Compare this post's direct profile visits against the average direct profile visits generated by *all other posts* by this user in the same timeframe.
- **New Followers**: 
  - Query `followers` where `following_id = :userId` AND `source_post_id = :postId`.
  - Compare vs average of other posts.
- **Organization Views**: 
  - Count impressions on this post where the viewer is an organization account.
  - Query `post_impressions` where `post_id = :postId` AND `viewer_org_id IS NOT NULL` within `current_period`.
  - This counts every view of the post that originated from an organization account (as tracked by `viewer_org_id` on the `post_impressions` table).
  - Compare vs average organization views across all other posts by this user in the same timeframe for the `vsAvg` trend.

### D. Audience Demographics
- Fetch all unique `viewer_id`s from `post_impressions` where `post_id = :postId` within the time range.
- Join with the `users` table to group by `location_city`, `location_country`, and `industry`.
- Calculate the percentage for each segment (`(count / total_unique_viewers) * 100`).
- Return the top 4-5 results for each category sorted descending.
